あらかじめ指定した $x$ 座標に対して、直線 $ax+b$ の追加と最小値クエリを効率的に処理するデータ構造。

## テンプレート引数

- `T`: 座標、直線の係数、および計算結果の型

## 記法

- $n$: コンストラクタに渡した座標の重複を除いた個数

# コンストラクタ

```cpp
LiChaoTree(const vector<T>& x, T INF)
```

クエリ対象の座標を指定し、直線を含まない状態で初期化する。`x` は内部で昇順にソートされ、重複する座標は除かれる。

## 引数

- `x`: クエリ対象の座標。入力時点ではソート済みでなくてもよく、重複を含んでもよい
- `INF`: 直線が追加されていないときに返す値

## 制約

- $1 \leq |x|$
- `INF` はすべてのクエリ結果以上
- 直線の値 $ax+b$ は `T` で表現できる

## 計算量

- 時間計算量: $O(|x| \log |x|)$
- 空間計算量: $O(n)$

# update

```cpp
void update(T a, T b)
```

直線 $ax+b$ を追加する。

## 引数

- `a`: 直線の傾き
- `b`: 直線の切片

## 計算量

- $O(\log n)$

# query

```cpp
T query(int k)
```

コンストラクタに渡した座標を昇順に並べて重複を除いた列の $k$ 番目の座標における、追加済みの直線の最小値を返す。直線が追加されていない場合は `INF` を返す。

## 引数

- `k`: クエリ対象の座標の添字

## 制約

- $0 \leq k < n$

## 計算量

- $O(\log n)$
