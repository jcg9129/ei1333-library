階乗、逆階乗、逆元を前計算し、順列・組み合わせ・重複組み合わせを求めます。

# コンストラクタ

```cpp
Enumeration<T> enumeration(size_t sz = 0)
```

$0$ から `sz` までの階乗、逆階乗、逆元を前計算します。前計算結果は同じ型 `T` のすべての `Enumeration` で共有され、必要に応じて自動的に拡張されます。

## 制約

- `sz!` が `T` 上で逆元を持つ
- `T` が素数 mod の整数型である場合、`sz < T::mod()`

## 計算量

初めて $N=$ `sz` まで前計算する場合、逆元を求める計算量を $I$ とすると、

- 時間計算量: $O(N+I)$
- 空間計算量: $O(N)$

# fact

```cpp
T fact(int k)
```

$k!$ を返します。

## 制約

- $0 \leq k$
- $k!$ が `T` 上で逆元を持つ

## 計算量

前計算済みの範囲なら $O(1)$ です。範囲外の場合は、自動的に $k$ まで前計算を拡張します。

# P

```cpp
T P(int n, int r)
```

順列の個数

$$
{}_n\mathrm{P}_r=\frac{n!}{(n-r)!}
$$

を返します。$r<0$ または $n<r$ の場合は $0$ を返します。

## 制約

- $0 \leq n$
- $n!$ が `T` 上で逆元を持つ

## 計算量

前計算済みの範囲なら $O(1)$ です。

# C

```cpp
T C(int n, int r)
```

二項係数

$$
\binom{n}{r}=\frac{n!}{r!(n-r)!}
$$

を返します。$r<0$ または $n<r$ の場合は $0$ を返します。

## 制約

- $0 \leq n$
- $n!$ が `T` 上で逆元を持つ

## 計算量

前計算済みの範囲なら $O(1)$ です。

# H

```cpp
T H(int n, int r)
```

$n$ 種類から重複を許して $r$ 個選ぶ方法の数

$$
{}_n\mathrm{H}_r=\binom{n+r-1}{r}
$$

を返します。$n<0$ または $r<0$ の場合は $0$ を返します。また、${}_0\mathrm{H}_0=1$ とします。

## 制約

- $0 \leq n$
- $0 \leq r$
- $(n+r-1)!$ が `T` 上で逆元を持つ。ただし $r=0$ の場合を除く

## 計算量

前計算済みの範囲なら $O(1)$ です。
